FAQ

Quick details that help with the first email.

What is the maximum print size?

The current maximum print footprint is about 180 mm x 180 mm. If your project is larger, it may be possible to split it into multiple printed pieces.

How long does international shipping take?

Shipping times vary by country, carrier, customs, and package size. A rough estimate is usually 7-21 business days after the print is finished.

What file types can I send?

STL, 3MF, OBJ, STEP, STP, and ZIP files are helpful. For modeling help, you can also send sketches, photos, measurements, or reference images.
